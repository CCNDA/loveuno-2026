# 新版愛諾園：跟原始設計不一致的地方

熊叔叔 2026-10-29 TG：「視覺修改跟原始設計不一致的地方要特別說明，屆時要和設計師討論」。

- 原始設計：loveuno-web 切版（https://loveuno-web.vercel.app，Next.js，只有畫面沒有後端）
- 新版：CCNDA/loveuno-2026（Laravel），測試站 test-loveuno-2026.ps194.net
- 每一條寫：原始設計怎麼做 → 新版怎麼做 → 為什麼 → 要跟設計師確認什麼

## 一、配色與字

對比都用 WCAG 2.x 相對亮度公式算的：白字對主按鈕 4.69、白字對紫褐 8.17、次要文字 #5e5049 對米白 7.52。

| # | 項目 | 原始設計 | 新版 | 為什麼 | 狀態 |
|---|---|---|---|---|---|
| 1 | 頁首文字 | 蜜桃底（約 #E4BBA4）配白字 | 蜜桃底配深褐字 #3d2a22 | 白字對蜜桃底對比 1.76:1，無障礙規定至少 4.5:1；深褐字 7.69:1。長輩讀者多 | 🟠 請設計師給一組符合 4.5:1 的頁首配色 |
| 2 | 色碼 | 設計稿原檔沒拿到 | 頁首 #E5BBA2、米白底 #FFFDF4 照切版 manifest.json（0.12.0 起）；主按鈕 #a3644a、次按鈕 #644754 是從截圖估的 | 切版的 CSS 裡沒有寫色碼（寫在元件裡）；manifest 有兩個 | 🟠 請設計師給正式色票 |
